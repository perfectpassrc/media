# media — Perfect Pass RC public image host

Public on purpose: email clients and social platforms fetch images from here by URL. Written by Jess's routines (marketing-brain) and by Bar. Rules: images only (jpg/png/gif/webp), no documents, no secrets, no customer data; a file is never deleted or renamed once an email has used it (sent emails keep pointing here).

URL pattern: `https://raw.githubusercontent.com/perfectpassrc/media/main/<path>` — e.g. `email/2026/yt-CpMNOCGkc-E.jpg`.
Naming: `email/<year>/yt-<videoId>.jpg` for YouTube thumbnails, `email/<year>/<PieceID>-<slug>.<ext>` for anything else.
